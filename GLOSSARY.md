# MergeMinds

Платформа курсов по программированию для факультета: преподаватели ведут курсы и задания, студенты сдают задания через `git push`, преподаватели проверяют diff и ставят оценки.

## Язык

### Курс и участники

**Пользователь** (_англ._ User):
Человек, вошедший через факультетский Keycloak; имеет ФИО.
_Избегать_: аккаунт, юзер

**Курс** (_англ._ Course):
Учебный курс с названием и описанием, находящийся в состоянии «в подготовке» (`draft`) или «открыт» (`open`).
_Избегать_: дисциплина, предмет

**Участие в курсе** (_англ._ Membership):
Связь пользователя с курсом, задающая его роль в этом курсе. Без участия у пользователя нет доступа к курсу.
_Избегать_: запись на курс, подписка

**Роль** (_англ._ Role):
Владелец (_англ._ owner), преподаватель (_англ._ teacher) или студент (_англ._ student) — всегда в рамках одного курса; глобальных ролей нет. Владелец у курса один — тот, кто его создал.

**Исключение из курса** (_англ._ Removal):
Удаление участия студента преподавателем; попытки и репозиторий студента сохраняются и возвращаются, если он вступит снова.
_Избегать_: бан, отчисление

**Подгруппа** (_англ._ Student Group):
Плоская группа студентов одного курса с уникальным в курсе названием; каждый студент курса состоит ровно в одной. Преподаватель может перевести студента в другую подгруппу того же курса, сохранив его попытки, проверки, допуски, репозитории и личные переопределения дедлайнов.
_Избегать_: группа, учебная группа (это группа университета, другое понятие)

**Ссылка-приглашение** (_англ._ Invite Link):
Многоразовая ссылка для вступления в курс с заранее заданными ролью, подгруппой (для студентов) и сроком действия.
_Избегать_: инвайт, код курса

**SSH-ключ** (_англ._ SSH Key):
Публичный ключ пользователя, по которому git-сервер узнаёт его при `git push`; у пользователя их может быть несколько.

### Задания

**Цепочка заданий** (_англ._ Task Chain):
Упорядоченный набор заданий курса, которые студент сдаёт по порядку в одном своём репозитории; разные цепочки сдаются независимо друг от друга. Одиночное задание — это цепочка из одного задания.

**Допуск к заданию** (_англ._ Task Unlock):
Разрешение студенту сдавать попытки по заданию цепочки. К первому заданию цепочки студент допущен сразу. К следующему его допускает преподаватель решением по попытке предыдущего задания при публикации проверки. Сдавать можно только последнее задание цепочки, к которому студент допущен. Допуск ограничивает сдачу, а не чтение условий: в открытом курсе студент видит условия всех заданий.
_Избегать_: открытие задания (путается с открытым курсом), разблокировка

**Репозиторий студента** (_англ._ Student Repository):
Репозиторий одного студента по одной цепочке, созданный из шаблонного репозитория при первом обращении студента к нему. Преподаватели курса могут его читать.

**Ключ цепочки** (_англ._ Task Chain Key):
Короткий идентификатор цепочки, входящий в адрес репозитория.

**Шаблонный репозиторий** (_англ._ Template Repository):
Репозиторий цепочки, из которого создаются репозитории студентов.
_Избегать_: стартовый код, заготовка

**Задание** (_англ._ Task):
Позиция в цепочке: условие, максимальная оценка и дедлайн.
_Избегать_: лабораторная, лаба, задача

**Ключ задания** (_англ._ Task Key):
Короткий идентификатор задания внутри цепочки, который студент указывает при сдаче.

### Сроки

**Дедлайн** (_англ._ Deadline):
Срок сдачи задания; не закрывает задание, а делит попытки на вовремя и опоздавшие. Может отсутствовать.
_Избегать_: срок закрытия

**Переопределение дедлайна** (_англ._ Deadline Override):
Дедлайн для подгруппы или студента вместо дедлайна задания: позже, раньше или «без дедлайна». Ожидание решения преподавателя автоматически дедлайн не сдвигает; при необходимости преподаватель задаёт переопределение вручную.
_Избегать_: продление

**Действующий дедлайн** (_англ._ Effective Deadline):
Дедлайн, который действует для конкретного студента: его переопределение, иначе переопределение его подгруппы, иначе дедлайн задания.

### Сдача и проверка

**Попытка** (_англ._ Attempt):
Неизменяемая сдача студента по заданию, к которому он допущен: коммит его репозитория, явно отправленный на проверку. Push без сдачи попытку не создаёт — он просто сохраняет работу.
_Избегать_: сабмит, посылка, решение

**Опоздавшая попытка** (_англ._ Late Attempt):
Попытка, созданная позже текущего действующего дедлайна студента. При изменении действующего дедлайна отметка опоздания пересчитывается; время создания попытки неизменно. Опоздание только отмечается и само оценку не снижает.

**База попытки** (_англ._ Attempt Base):
То, относительно чего показывается diff попытки: предыдущая попытка по этому заданию, иначе последняя попытка по предыдущему заданию цепочки, иначе шаблонный репозиторий.
_Избегать_: baseline, родитель

**Оценка за задание** (_англ._ Task Grade):
Оценка последней проверенной попытки студента по заданию.
_Избегать_: итоговая оценка, лучшая оценка

**Проверка** (_англ._ Review):
Опубликованный результат проверки попытки: оценка, общий отзыв и комментарии преподавателя к строкам. При публикации проверки числовая оценка обязательна при любом решении, в том числе при возврате на доработку.
_Избегать_: ревью, рецензия

**Список попыток** (_англ._ Attempt List):
Страница, на которой преподаватель просматривает попытки студентов и отбирает их фильтрами, в том числе ожидающие проверки. Отдельной страницы или очереди «Ждут проверки» нет.

**Решение по попытке** (_англ._ Attempt Decision):
Обязательный выбор преподавателя при публикации проверки, без варианта по умолчанию: вернуть на доработку либо допустить к следующему заданию; для последнего задания вместо допуска — принять. Принять решение без публикации проверки нельзя. Уже принятое решение можно изменить в шапке попытки, только пока студент не сдал новую попытку.

**Возврат на доработку** (_англ._ Rework):
Решение по попытке, разрешающее студенту сдать новую попытку по тому же заданию. Предыдущая попытка и её проверка остаются в истории; пока решения нет, новую попытку сдавать нельзя.
_Избегать_: сбросить попытку, откатить попытку

**Черновик проверки** (_англ._ Review Draft):
Неопубликованные оценка, общий отзыв и комментарии к строкам по попытке. Один на попытку; виден преподавателям курса, студенту — нет.

**Оценка** (_англ._ Grade):
Число от 0 до максимальной оценки задания с не более чем одним знаком после запятой.
_Избегать_: балл, отметка

**Тред к строкам** (_англ._ Line Comment Thread):
Обсуждение, привязанное к строкам diff попытки.

**Бронь проверки** (_англ._ Review Lease):
Истекающее право одного преподавателя менять проверку попытки.
_Избегать_: блокировка, лок
