# Архитектура

Публичный API каждого модуля — `index.ts`. Контракт oRPC определяет вход,
выход и типизированные ошибки до реализации обработчиков. Платформа не
зависит от предметных модулей. Сборка приложения связывает модули через
публичные API и передаёт обратные вызовы вместо обратных импортов.

Граф разрешённых зависимостей (стрелка от потребителя к поставщику):

- invitations → courses
- tasks → courses
- attempts → tasks
- reviews → attempts
- git → attempts
- notifications → tasks
- каждый модуль → platform
- app → публичные API модулей, platform

Курсы владеют участием, ролями, подгруппами и состоянием курса; попытки —
допусками и переходами по цепочке. Только владелец таблицы может писать в
неё. Чтение через join допустимо в рамках направленного графа.

Тесты вызывают публичный oRPC API с настоящим Postgres и управляемыми часами.
Обычные тесты откатывают транзакцию, гонки используют независимые соединения.
Вспомогательный тестовый код запрещён в предметном коде.

UI модулей использует Mantine и платформенные компоненты. Собственные CSS,
`className`, `style` и UI DSL запрещены. Начальная загрузка выполняется в loader,
данные читаются через useSuspenseQuery. Ошибки и загрузка обрабатываются на
границе маршрута.

`example` — технический сквозной пример, не реализация предметного модуля.
