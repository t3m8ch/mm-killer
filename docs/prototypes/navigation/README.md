# Прототип навигации для #4

Одноразовый прототип для согласования сайдбара, хлебных крошек и перехода в проверку попытки. Не вливать в master. После настоящей реализации закрыть draft PR, сохранив ветку как источник. Выбор варианта ещё не сделан.

## Запуск

Из корня: `pnpm install --frozen-lockfile`, затем `pnpm prototype`.
Команда использует существующее окружение `mise.toml`; mise и инструменты проекта должны быть установлены. Прототипу не нужны миграции, seed или подключение к БД: сервер использует стандартную конфигурацию, но экраны работают с данными в памяти и не вызывают API.

Открыть `/prototype/courses/1?variant=A`. Все страницы живут под `/prototype/`, чтобы не менять настоящие вход и главную. После префикса сохранены согласованные пути и числовые ID. Изменения форм сбрасываются после перезагрузки.

## Варианты

- **A — единое дерево:** общие ссылки, все курсы и разделы выбранного курса в одной панели. [Скриншот](variant-A.png).
- **B — курсы + разделы:** узкая панель выбора курса, отдельное меню разделов; выбор соседнего курса из крошки. [Скриншот](variant-B.png).
- **C — рабочее пространство:** общий хедер, переключатель курса над контекстным меню; соседние задания доступны из крошки. [Скриншот](variant-C.png).

Переключатель снизу и клавиши ← / → меняют `?variant=`, сохраняя страницу, роль и фильтр. Стрелки в полях и меню не перехватываются. Переключатель виден только в dev. Под «Состояние» показаны параметры прототипа. Роль влияет только на видимость ссылок, это не реализация прав доступа.

## Проверка с 15 курсами

Предварительно понравился вариант A — единое дерево. Для проверки плотности добавлены 15 курсов с короткими и длинными названиями. Список один и тот же во всех вариантах и на главной. Проверить прокрутку дерева, доступность нижних курсов, контекстное меню выбранного курса и возврат из diff. Итоговое согласование ещё впереди. [Нижняя часть дерева с активным курсом №15](fifteen-courses.png).

## Что попробовать

Открыть «Мои курсы», выбрать курс, затем задание и попытку. На [диффе](diff.png) обе части основной навигации скрыты без отступа; кнопку навигации оставить в хедере рядом с крошками. Кнопка открывает [панель поверх содержимого](diff-navigation.png). Дерево файлов остаётся слева, переходы и Escape закрывают панель. При выходе из diff возвращается обычная навигация.

Другие экраны: вход, приглашение, личные настройки, настройки курса, участники, список попыток с фильтром в query. На настройках курса можно изменить название и проверить немедленное обновление крошек (это локальное состояние, не интеграция с Query). Второй курс имеет длинное название. Переключатель роли позволяет посмотреть скрытие преподавательских ссылок. [Мобильная панель](mobile.png).

Содержимое страниц, сдача задания и проверка — заглушки. Крошки строятся по моковым данным, у попытки известно задание независимо от глубины URL. Публичные API модулей, loader/useMatches, staticData, настоящий кэш и серверные права остаются для реализации #4 и соответствующих модулей. Это материал для выбора UX, не выполнение всех критериев #4.
