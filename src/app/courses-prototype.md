# Прототип курсов · #5

Одноразовый UI-прототип в ветке `prototype/issue-5-courses`. Проверяем, удобны ли согласованные список курсов, форма и работа с подгруппами в общей оболочке. Production-БД, API и авторизация не реализуются.

## Запуск

После `pnpm install --frozen-lockfile` выполнить `pnpm prototype:courses` из корня репозитория. Команда использует локальную конфигурацию `mise.toml` и открывает `/prototype/courses` на порту 4315. Нужен установленный mise; браузер можно открыть вручную. Прототип не отправляет запросов к БД; общий сервер требует корректный DATABASE_URL при запуске.

## Варианты

Один маршрут `/prototype/courses`, параметр `variant=A|B|C`. Переключение нижней панелью или стрелками клавиатуры, кроме редактируемых полей и модалок. Состояние сохраняется при переключении варианта, но не при перезагрузке.

- A: единая таблица, фильтр подгруппы сверху.
- B: список подгрупп слева от таблицы; на узком экране переносится вверх.
- C: таблицы секциями подгрупп, пустые секции видны сразу.

Прямой пример: `/prototype/courses?course=1&view=members&variant=B`.
Параметр `view`: `list`, `create`, `home`, `members`, `settings`. Числовой `course` сохраняется при переименовании.

## Что можно попробовать

Поиск курса и пустой поиск; создание и изменение общей формой; эмодзи курса и вставка в описание; поиск эмодзи «книга»/`book`; личная история до перезагрузки; выделение Markdown; предпросмотр и главная курса с одинаковым безопасным рендерером.

Открытие курса с отменой/подтверждением; возврат в подготовку без студентов и запрет со студентами; демонстрационный выбор роли и экран «Курс готовится» для студента.

Выбор подгруппы, выделение строк или всех видимых, счётчик и массовый перевод со сбросом; создание/переименование подгрупп, конфликт имени; удаление только пустой и не последней; исключение/восстановление участия; состав преподавателей для владельца.

Для пустого списка есть кнопка «Демо: пустой список», для исходного набора — «Сбросить демо». Полное релевантное состояние раскрывается внизу каждого экрана.

## Границы и результат

Проверено в настоящем приложении через Playwright и видимые элементы интерфейса. Это проверка UX, а не серверных гарантий. Данные студентов синтетические. Восстановление участия и добавление преподавателя по ФИО — демонстрационные действия, не механизмы production-вступления или приглашения.

Редактор реализует только демонстрационное подмножество Markdown: заголовки, жирный, курсив, списки. React выводит HTML текстом, без dangerouslySetInnerHTML. Пикер содержит небольшой двуязычный словарь, не полный каталог Unicode. Пороговые значения и обязательность полей не утверждаются прототипом.

Компоненты Mantine: формы, таблицы, поповеры, меню, модалки, вкладки и выбор. Собственный CSS нужен для строк списка, двухколоночной компоновки и фиксированного dev-переключателя. Оболочка, sidebar, крошки, темы и мобильная панель переиспользуются из приложения. Сборка прототипа живёт в `app`, поскольку связывает sidebar приложения и UI платформы.

Предварительный вывод: все три компоновки позволяют выполнить согласованный сценарий, A ближе к спецификации. Победитель не выбран пользователем; никакое решение не перенесено в production. Прототип и панель доступны только в dev. Issue #5 остаётся открытой для выбора UX и последующей полноценной реализации.

## Замечания инструментов

Первый lint/typecheck: неиспользуемый импорт, вложенный тернарный оператор и группировка стейтментов. Исправлены удалением импорта, разделением вычислений и пустыми строками; проверки не ослаблялись.

Первый Easement: `.ui.tsx` импортировал integration-файлы sidebar/course-branch. Файл сборки переименован в `.tsx` внутри app, как остальные связующие компоненты. Правила не изменялись.

Первый запуск без mise: отсутствовал DATABASE_URL. Локальная конфигурация передана явно; команда запуска использует mise. В консоли браузера отдельный 404 `/favicon.ico` (ресурс отсутствует в приложении), ошибок исполнения прототипа не замечено.

Первый браузерный прогон остановился из-за селекторов драйвера: две одноимённые кнопки открытия и Mantine Select с ролью combobox, не textbox. Селекторы уточнены, сценарии продолжены успешно. Автоматические тестовые файлы не добавлялись по правилам prototype.

Knip сообщает о существующем шаблоне `src/modules/*/public.*` без совпадений: предметных модулей в репозитории пока нет. Oxfmt сообщает об использовании настроек по умолчанию: конфигурационный файл не задан. Easement выводит принятые исключения module augmentation TanStack из существующей конфигурации; новых исключений не добавлялось.

Commit hook отклонил первую попытку: заглавное `UI` в subject нарушило `subject-case`, длинная строка body превысила 100 символов. Сообщение переписано строчными и разбито на строки; hook не отключался.

Pre-push после добавления команды запуска остановил Knip: `mise` отсутствует в npm-зависимостях. Это внешняя утилита из контракта проекта, как `easement`; добавлено точечное `ignoreBinaries: mise`. Это исключение только учёта внешнего бинарника, не обход проверок кода. Затем pre-push повторён.

## Итерация по обратной связи

Пользователь выбрал направление A. В нём фильтр заменён горизонтальными кнопками подгрупп: переименование внутри кнопки, удаление только для пустой и не последней. B/C сохранены для сравнения. Создание/переименование и добавление преподавателя открываются поповером у кнопки.

Строка студента переключает выбор целиком, вложенные чекбоксы и меню не вызывают двойного переключения. Панель перевода закреплена у нижнего края вне потока таблицы; служебный бар перенесён наверх вправо. Роль, сброс, пустой набор и состояние убраны в поповер «Демо». Лишние пояснения удалены из экранов прототипа; объяснения последствий и запретов оставлены.

Редактор: иконки форматирования под текстом слева, эмодзи справа; добавлены вставка и рендеринг нумерованных списков. Частые эмодзи дополняют стартовый набор, не заменяют его. Сохраняется позиция курсора после вставки.

Браузерная проверка: координата строки до/после выделения совпала; проверены checkbox/row без двойного toggle, поповеры и CRUD подгрупп, массовый перевод, нумерация и предпросмотр, последовательная вставка и наличие стартовых эмодзи. Первый assertion редактора выявил несинхронизированную сохранённую позицию курсора после вставки; позиция обновляется вместе с текстом, повторная проверка прошла. Просмотрены тёмные desktop/mobile скриншоты. Format, lint, typecheck, Easement, Knip и build прошли; новых подавлений нет. Выбор A не означает готовность production-кода.
